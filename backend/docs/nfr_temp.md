Security: password storage	Passwords can't be recovered if the database leaks	argon2id with OWASP settings. A failed login takes the same time whether or not the username exists, so usernames can't be discovered that way	common/security/hashing.ts	✅
Security: password policy	Strong passwords	8–32 characters, uppercase, number and special character, checked on both backend and frontend	auth/password-policy.ts, frontend/src/lib/password-policy.ts	✅
Security: authorization	Students only see their own data and courses they're enrolled in; instructors only manage their own courses	Login guard and role guard on every route, plus per-course checks (staff, enrolled, preview lessons). Checked on Cloud Run: 401 / 403 / 200	common/guards/, access/access-policy.service.ts	✅
Security: input validation	Reject bad or unexpected input	A global validation pipe rejects unknown fields and validates each request body	app.module.ts	✅
Security: abuse protection	Brute-force and spam protection	Rate limits per user (per IP when not logged in): 120/min overall, 10/min on login and enrollment routes. The counters live in each server instance's memory, so with several Cloud Run instances each one counts separately	user-throttler.guard.ts	🟡
